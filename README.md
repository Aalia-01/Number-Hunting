Number Guessing Game:-

Overview
A simple Python console game where the player tries to guess a randomly generated number between 1 and 50.

Technologies Used:-
- Python
- Random Module

How It Works:-
- The program generates a random number between 1 and 50.
- The player enters a guess.
- The game provides hints:
  - "TOO LOW" if the guess is smaller than the target number.
  - "TOO HIGH" if the guess is larger than the target number.
- The game continues until the correct number is guessed.

Files:-
